# SEO-аудит сайта exp76.ru от 31.05.2026

## Что проверено

- Обход sitemap: 192 публичные страницы из `post-sitemap.xml` и `page-sitemap.xml`.
- Проверены: HTTP-статус, title, description, H1/H2, наличие явных заглушек, одинаковой старой картинки `001-02-1.webp`, пустых/слабых текстов и неудачных внутренних формулировок.
- После правок повторный обход показал: ошибок загрузки нет, пустых title/description нет, явных заглушек и `001-02-1.webp` в HTML нет.

## Что исправлено сразу

- Убрана внутренняя фраза-заглушка из текста категории "Осушение участка".
- Синхронизирован импорт "Отмостки вокруг дома" с актуальной структурой без заголовков `Проблема 1` и `Пункт 1`.
- Исправлена фраза в статье по технологии укладки плитки: вместо внутреннего "клиент получает" теперь нормальный текст для посетителя.
- Для блоговых SEO-постов проставлены тематические изображения вместо старой общей картинки.
- В шаблоне SEO-блога добавлен fallback на тематические изображения из `seo-service-photos`, если в ACF не выбрано фото.
- В шаблоне новой услуги добавлен fallback на тематические изображения для карточек проблем и кейсов, если фото не выбрано в ACF.
- Обновлены импорты и данные на сайте, кэш очищен.

## Вопросы заказчику для усиления коммерческих страниц

- Какие минимальные цены можно публиковать по направлениям: дренаж, осушение, ливневка, отмостка, плитка, автополив?
- Можно ли показывать диапазоны цен: "от ...", "обычно ...", "после осмотра"?
- Есть ли реальные фото по каждому направлению, которые можно закрепить за услугами и статьями?
- Какие города и районы точно обслуживаются постоянно: Ярославль, Рыбинск, Углич, Тутаев, Переславль, другие?
- Какие услуги компания не хочет продвигать отдельно, даже если они есть в старых материалах?
- Можно ли публиковать сроки работ по типовым объектам?
- Есть ли 5-10 сильных кейсов с фото до/после, стоимостью или хотя бы объемом работ?

## Рекомендации

- Прокачать страницы фотогалереи: сейчас именно карточки отдельных объектов самые тонкие по тексту. Их лучше превратить в полноценные кейсы с задачей, решением, составом работ, сроками и фото.
- Для каждой новой SEO-рубрики добавить 2-3 реальных кейса в ACF, чтобы блок "Примеры работ" был не декоративным, а продающим.
- После получения цен от заказчика расширить страницу калькулятора и коммерческие блоки по направлениям.
- Продолжать использовать схему: рубрика = коммерческая посадочная, категория 74 = услуги, категория 72 = статьи, фотогалерея = реальные кейсы.
- Для новых блоговых постов сразу выбирать уникальное фото и alt, чтобы не возвращать одинаковые изображения.
