# Expanded architecture targeted SERP batch

This immutable second batch contains 23 commercial-intent probes for candidate
pages whose first representative SERP was broad, product/information heavy, or
overlapped its hub. The queries add price, service and local modifiers instead
of silently approving a weak destination.

Estimated deferred-search cost: 0.7015 RUB. Together with the 92-query primary
batch, the expanded architecture validation costs at most 3.5075 RUB.
