# Контрольная выдача для статей

Каталог содержит отдельный неизменяемый срез Яндекс Search API для 13
информационных направлений из `page_architecture.csv`. Он не расширяет и не
переписывает основной корпус из 141 коммерческого запроса: его задача —
проверить формат выдачи непосредственно перед подготовкой статей.

- собрано 13 запросов и 130 органических результатов;
- дата сбора зафиксирована в `source-manifest.json`;
- расчётная стоимость deferred API — 0,3965 ₽;
- в JSONL сохранены только rank, URL и title, без XML, сниппетов, ключей и
  авторизационных заголовков;
- целостность проверяется SHA-256 для очереди, 13 operation records и 13
  JSONL-файлов.

Ручное решение находится в
`../../reviews/article_destination_serp_reviews.csv`: 12 направлений имеют
устойчивый отдельный информационный формат. Запрос про расчёт инженерного
благоустройства объединён с материалом о расчёте стоимости: у них три общих
URL в top-10, а отдельная выдача смешивает учебные PDF и тот же ценовой интент.

Проверка без сети:

```powershell
python -m unittest tools.test_article_serp_evidence -v
python -m tools.seo_semantics.cli serp-api-verify --queue seo-data/2026-08-exp76-services/raw/article-serp/serp-queue.csv --serp-dir seo-data/2026-08-exp76-services/raw/article-serp
```
