# Статьи для хабов S9–S15

Каталог `articles/` содержит по одному готовому JSON на утверждённый информационный URL из `legacy_article_architecture.py`. Формат повторяет используемые на сайте ACF-поля `blogseo_*`, но хранит статью самостоятельным объектом, чтобы её можно было проверять и собирать в импортный пакет без копирования текста.

В каждом материале обязательны:

- минимум шесть содержательных разделов и пять FAQ;
- SEO title и description;
- проверенное изображение с `exp76.ru/wp-content/uploads/`;
- видимые в тексте ссылки на родительский хаб и одну релевантную подуслугу;
- не менее 800 слов в лиде, разделах и FAQ;
- `sources` как пустой список для материалов без внешних утверждений или как список проверенных источников. Для правового материала S15 нужны минимум два официальных источника с датой проверки.

Проверка текущих файлов:

```powershell
python -m tools.legacy_article_content
```

Проверка полного набора из 11 утверждённых статей:

```powershell
python -m tools.legacy_article_content --complete
```

Сборка локального payload для уже используемого `inc/import-drenazh-blog.php`:

```powershell
python -m tools.legacy_article_content --complete --render-import
```

Результат записывается в `import/legacy-services-blog-import.json`. В payload попадают только поля, которые читает старый импортёр: `slug`, заголовок, excerpt/content, порядок, категории, изображение и ACF. Технические поля архитектуры `destination_id`, `service_id`, `internal_links` и `sources` остаются в исходниках и в импорт не копируются.

Все материалы получают существующую общую категорию блога `72`. Категория дренажа `87` намеренно не используется, потому что пакет объединяет статьи семи разных направлений. Валидатор дополнительно сверяет ID, заголовок, URL и владельца хаба с семантической архитектурой.

Команда только пишет локальный JSON. Она не подключает WordPress, не запускает PHP-импорт и не меняет сайт.

Точная копия payload хранится в теме как `import/legacy-services-blog-import.json`. Файл `inc/import-legacy-services-blog.php` только предоставляет ручную функцию `land76wp_run_legacy_services_blog_import()` и передаёт путь общему импортёру. Подключение wrapper в `functions.php` не запускает импорт и не регистрирует автоматических хуков.
